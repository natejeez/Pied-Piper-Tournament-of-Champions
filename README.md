# Harry Men Pied Piper Championship

Data repository for the Harry Men Pied Piper Championship.

## 2026

- 9 participants
- 8 submissions per participant
- 72 initial submissions
- 8 play-in matches
- 64-song main bracket
- 2026 ruleset: `docs/rules/Harry_Men_Pied_Piper_2026_Ruleset.md`
- Data schema: `docs/data-schema-2026.md`

The authoritative tournament data is kept separate from the website presentation layer. Administrative intake data containing private email addresses is stored under `data/2026/admin/` and should never be exposed by the public website.
